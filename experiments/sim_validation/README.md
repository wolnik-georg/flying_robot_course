## 1. Formation validation matrix

1 EXPECTED, 0 defects.** Full write-up: [`../../docs/12_Sim_Formation_Validation_Report.md`](../../docs/12_Sim_Formation_Validation_Report.md).

| File | Contents |
|---|---|
| `matrix_results.md` | One row per run: scenario, controller, robot count, verdict, mean \|e_z\|, RMSE, max tilt, divergence flag, recording coverage, parameters, and the `record_states` directory the numbers came from |
| `matrix_results_geo_only.md`, `matrix_results_prefix.md` | Earlier partial runs, kept for the record |
| `run_*.log`, `client_*.log` | Server and client output from the most recent run of each controller. **Overwritten each run** — copy anything worth keeping |
| `EXTERNAL_REVIEW_BRIEF.md` | The brief sent out for independent review of scenario-set completeness |

    ../logs/A3_<stamp>.meta.json  ~/Desktop/crazyswarm2/state_geo/<ts>/csv --controller geo

## 2. Residual-learning dry run

Output of `../analysis/run_residual_dryrun.sh` — the full collect → train → upload → enable →
measure loop, with no drone. Design and interpretation:
[`../../docs/13_Residual_Learning.md`](../../docs/13_Residual_Learning.md) §7.

| File | Contents |
|---|---|
| `RESIDUAL_DRYRUN.md` | **The report.** Prediction quality, compensation effect, and the sanity checks |
| `residual_collect.csv` | Phase 1 — geometric, no network. The training set |
| `residual_predict.csv` | Phase 3 — weights loaded, `rnn.en=0`. Prediction and measurement independent |
| `residual_compensate.csv` | Phase 4 — `rnn.en=1` |
| `residual_weights.npz` | The trained weights, with provenance in its `meta` field |
| `dryrun_*.log`, `dryrun_client_*.log` | Server and client output per phase. Overwritten each run |

```bash
../analysis/run_residual_dryrun.sh --scenario A3 --dz 0.30      # ~13 min
```

**Phase 3 is the phase that carries the result.** With the network in the loop (phase 4) the
residual it sees is the one that survived its own compensation, so a small number there is equally
consistent with a good model and a stable-but-wrong feedback loop. Only phase 3 separates them.

## The caveat that applies to everything in this folder

These are simulation numbers. In particular, the residual here is **generated by the simulator's
own Neural-Swarm2 model and then fitted by a model of the same family** — learning a network's
output with another network is a far easier problem than learning real air.

What this folder establishes: the scenarios are geometrically correct, the controllers fly them,
and the residual-learning pipeline works end to end through the code paths the lab will use.

What it does not establish: that any method works on a real drone. **The simulator can disprove a
controller; it cannot validate one.**
