# Thesis Experiments

Working area for the thesis's own experimental work, separate from the archived course-phase
material in `archive/old_logs/` and `archive/Controls/`.

- `logs/` — raw flight logs (CSV) from thesis experiments (e.g. the 2-robot comparison protocol in `docs/05_Experimental_Protocol_2Robot.md`)
- `analysis/` — analysis scripts/notebooks and generated plots/metrics derived from `logs/`
- `protocols/` — experiment-run checklists / configs, one per experiment session

See [`docs/`](../docs/) for the experimental protocol and thesis planning documents this folder supports.
