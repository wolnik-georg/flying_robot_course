# crazyflie-firmware local patches

Apply on a clean **bitcraze/crazyflie-firmware** checkout (this tree pins `stable-june20`).

Order matters for overlapping files — use:

```bash
FW=~/Desktop/crazyflie-firmware   # or a throw-away worktree
PATCH=$HOME/Desktop/flying_robot_course/flying_drone_stack/firmware_patches
cd "$FW"
for p in \
  stabilizer_stack_8x.patch \
  usddeck_96_variables.patch \
  controller_indi_cf21bl.patch \
  controller_oot_slots.patch \
  ns2_residual_module.patch \
  controller_omar_indi.h.patch \
  controller_omar_indi.c.patch \
  controller_tk_indi.c.patch \
  naindi_gyro_no_lpf_math3d.patch \
  platform_cf21bl_omar_constants.patch \
  rpm_deck_bcRpm.patch \
  cffirmware_bindings.patch
do
  git apply --check "$PATCH/$p" && git apply "$PATCH/$p"
done
make bindings_python
```

Regenerate from the live firmware tree:

```bash
cd ~/Desktop/crazyflie-firmware
# tracked files — same paths as in README loop above
git diff src/config/config.h > "$PATCH/stabilizer_stack_8x.patch"
# … see LOCAL_MODIFICATIONS.md § How to restore everything
```

## ns2_residual_module.patch (2026-10-14)
NS2 learned residual in C for the Omar C controller tree (`src/modules/{interface,src}/ns2_residual.{h,c}`, Kbuild line). Must be applied **before** `controller_omar_indi.h.patch` (the header includes `ns2_residual.h`). The flash weights are not in the patch: `flying_drone_stack/firmware_app/ns2_weights.c`, generated by `tools/residual/export_weights_c.py` from `ns2_v1.npz`. Spec: `docs/ns2_c_module_spec.md`.

## controller_omar_indi.{c,h}.patch — ns2_mode (2026-10-17)
Both patches are new-file patches (the Omar controller is untracked in the firmware tree) and were regenerated from the live files (`git diff --no-index -- /dev/null <file>` with the `a/` path fixed). Added: parameter `ctrlOmarIndi.ns2_mode` (0 = Version A, plain sum, default; 1 = Version B, INDI works only on what NS2 left over), one extra 30 Hz Butterworth filter on the NS2 output, log variable `ctrlOmarIndi.a_nn_fz`. With `ns2_mode = 0` the controller is bit-identical to the build before (`host/test_omar_ns2_off_identical.py`, all four replays identical). Order list above is unchanged.
