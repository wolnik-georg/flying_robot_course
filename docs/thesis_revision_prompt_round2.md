# FACT SHEET — the final controller, as implemented (verify each line against the code; correct this sheet if the code differs, and say so in the open-items file)
**One controller, three switches.** Switch A (bit 0): the measured residual enters the position loop. Switch B (bit 1): the measured-moment correction enters the attitude torque. Switch C: the learned residual enters the position loop. S0: none; S1: A and B; S2: C; S3: A, B and C. Both vehicles run the same controller; the top vehicle is always S0 and carries no learned term. Learned term only on the bottom (subject) vehicle.
**Rates.** The controller body executes at 500 Hz inside a 1 kHz main loop; the motion-capture pose arrives at 100 Hz; the SD log is written at 500 Hz; the learned residual is evaluated every 10th main-loop tick (100 Hz) and held in between. Neighbour positions arrive over the radio with timestamps; relative velocity is obtained by finite differences (rules for first sample, repeated timestamp, gap ≥ 500 ms — see the code).
**Position loop.** a_d = a_ff + K_v e_v + K_p e_p + (vertical-only integral K_i,z ∫e_z, with a limit; other axes none); study values: K_p = 7, K_v = 4 on all axes (shared by S0–S3), K_i,z = 1.5 in all four. a_ff includes gravity compensation. No velocity-error conditioning (the round-1 text about a 0.6 m/s limit and a 10 Hz filter described the retired implementation and must go). With the switches: F_d = a_d + a_indi − a_nn; collective thrust f = m F_dᵀ R e₃; desired attitude from the direction of F_d and the yaw reference.
**Measured residual (switch A).** a_indi = a_rpm,f − a_imu,f, where a_rpm = (Σ_k k_t ϖ_k²)/m · R e₃ − g e₃ (one thrust constant for all rotors, ϖ_k from the optical rotor-speed deck, raw) and a_imu is the estimator's world-frame acceleration (gravity removed); both pass second-order Butterworth low-pass filters at 30 Hz sampled at 500 Hz. The residual of Chapter 3 is a_res = a_imu,f − a_rpm,f, so adding a_indi subtracts the residual (consistent with Section "sign"). Controller mass parameter 0.0427 kg. The study does not use the DShot rotor-speed telemetry or the plausibility filter of the retired implementation for control (check what Chapters 3 and 5 say about rotor-speed sources and the plausibility filter; correct them to the optical deck; the deck being unavailable means switches A and B cannot run).
**Attitude loop.** e_R = ½(R_dᵀR − RᵀR_d)^∨, ω_r = RᵀR_d ω_d with ω_d from the jerk (flatness map) and ω̇_d from the snap; torque (Lee et al. form): τ = −K_R e_R − K_ω(ω − ω_r) − K_I ∫e_R + ω × Jω − J(ω̂ ω_r − RᵀR_d ω̇_d), K_R = diag(0.007, 0.007, 0.008), K_ω = diag(0.00115, 0.00115, 0.002), K_I = 0.03 (attitude integral ACTIVE), J = diag(16.57, 16.66, 29.26)·10⁻⁶ kg m² (check the source of these inertia values in the code comments and what Chapter 5 / Chapter 4 currently claim about the inertia; if the code comment names a different vehicle's identification, state exactly that as a deviation and flag it). Switch B adds to τ the correction τ_rpm,f − J α_f: τ_rpm from the four rotor thrusts (arm length, rotor drag-to-thrust ratio), α the angular acceleration by differencing the gyro, both filtered at 30 Hz. It is an ADDITIVE correction to the full geometric torque, not a replacement of the torque law — the round-1 equations "reference angular acceleration / effectiveness factor / incremental law" described the retired implementation and must be replaced. Identify which equations of which held paper this structure corresponds to (candidates: Cobo-Briesewitz et al. eqs. 8a–b and 10a, Tal & Karaman) by reading the PDFs; state every difference as a deviation.
**Learned residual (switch C).** Deep-sets network: neighbour encoder 6→25→40→40→20, ground-effect encoder 4→25→40→40→20 (always on, input [−z, −v_x, −v_y, −v_z]), decoder 20→40→40→40→1, ReLU, last layer linear; neighbour inputs relative position and velocity; a neighbour is included only if |Δx| < 0.2 m, |Δy| < 0.2 m and |Δv_x| < 1.5 m/s; at most three neighbours; output a scalar vertical force in grams, converted to N and divided by the controller mass; vertical component only; clamped at 8 m/s²; subtracted: a_d − a_nn. Weights are frozen in flash (19,297 in the layout, 11,461 used). **Training data and labels.** The learned model is retrained on DEDICATED training flights (never the comparison flights): a grid of vertical separations, lateral offsets and speeds in the library's scenarios plus randomised waypoint flights (new scenario, planned offline and checked by the same safety gate as every scenario, seeded, with the lower and upper vehicle planned together, upper vehicle always at least 0.25 m above, goals of the upper vehicle biased towards the lower one's horizontal position so that the pair is inside the network's gate most of the time), flown with S0.
