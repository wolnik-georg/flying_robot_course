## 3. Biggest challenge — SD pairing & merge (read this first)

### 3.1 Three different “labels” (do not conflate)

1. **Card volume:** `THESIS1` / `THESIS2` — **not** bottom/top.
2. **Drone role in flight:** **cf5 = bottom**, **cf_second = top** (in meta `names` / `roles`).
3. **Card file counter:** `thesis00`, `thesis01`, … on **each card independently**.

**Which card sat in cf5 vs cf_second changes by session slice:**

| Time (approx) | Card in **cf5** | Card in **cf_second** |
|---------------|-----------------|------------------------|
| Morning A8 ~12:08–12:11 | **THESIS2** | **THESIS1** |
| Midday A7/A1 + afternoon A3/A8/A1 ~12:37–13:30 | **THESIS1** | **THESIS2** |

For merge: **bottom bin** = file from card that was in **cf5** that flight; **top bin** = file from
card that was in **cf_second**. Symlink as `cf5_*` and `cf_second_*` for column names.

### 3.2 Same `thesisNN` on both cards is often WRONG

Counters **desync** when:
- **0-byte files:** `thesis05` (aborted A1 `12-41-59`), **`thesis12` empty on THESIS1** (A3
  `13-05-58` — cf5 has **no** uSD for that rep; THESIS2 has `thesis12`).
- **Abort without matching stop on both cards:** `13-26-25` (~143 radio rows) — no new non-empty
  file pattern on THESIS1 afternoon block.

**Confirmed desk result:** For **`13-25-10`** (A1, dz=0.20), merge **passes** with **THESIS1
`thesis15` + THESIS2 `thesis13`**, **not** 15+15. Top RMS ~38.7 cm for same-index pairing.

### 3.3 Why merge “fails” on A1 (two separate causes)

| Cause | Symptom | What to do |
|-------|---------|------------|
| **Wrong bin pair** | One side RMS **30–40 cm** | Search **(i,j)** thesis indices ±5 around expected counter; enforce **unique (i,j)** per chronological stamp; use **meta `params.dz`** to reject ambiguous A1 matches. |
| **cf5 z tracking** | Bottom RMS **15–21 cm** with plausible pair | Real physics / control; may need **z gain tune** or documented gate exception — **not** fixed by swapping cards alone. |
| **Long card files** | Flight at **~13 s** into file | **Expected** post–`usec.reset` (see `find_flight_window.py`); merge `--meta` alignment should handle if **pair is correct**. |

### 3.4 What NOT to do

- Do **not** pair uSD to radio by **git pull timing**.
- Do **not** assume **THESIS1 = bottom** for the whole day.
- Do **not** treat **identical A1 `params`** as uniquely identifiable by trajectory correlation alone
  (tool warning in `find_flight_window.py`).
