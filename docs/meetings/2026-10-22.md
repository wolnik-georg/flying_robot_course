## Questions:
- **INDI + NS2 (S3): plain switches (A) or INDI only on what NS2 left over (B)?**
  - **Problem**
    - INDI measures the force on the vehicle (IMU against motors), not the remaining error; extra thrust changes both, so INDI still sees the full downwash `d` after NS2 has cancelled it
    - flights confirm it: the measured push in S3 equals the one in S1 (A1 −2.86 vs −2.89 m/s², A8 about −1.2 vs −1.1) while NS2 predicts −1.0 … −2.3
    - with both on, a push of 1 is corrected twice (2); S3 has the smallest dip (−1.9 cm) but an upward overshoot (A1 +2.6 cm vs −0.6 cm for INDI alone, A8 up to +5.7 cm)
  - **Version A — plain switches (flown, the current S3)**
    ```c
    if (NS2_on)  a_d -= a_nn;                 // NS2: predicted push, feed-forward
    if (INDI_on) a_d += a_rpm_f - a_imu_f;    // INDI: measured push
    // push of 1: NS2 adds 1, INDI adds 1 -> 2
    ```
  - **Version B — INDI works only on the rest (implemented and tested in simulation, not flown)**
    ```c
    a_nn_f = lowpass30(a_nn);                         // NS2 through the same 30 Hz filter as the measurement
    if (NS2_on)  a_d -= a_nn;                         // NS2 exactly as in A
    if (INDI_on) a_d += (a_rpm_f - a_imu_f) + a_nn_f; // INDI minus what NS2 already handles
    // push of 1: NS2 adds 1, INDI sees the push minus NS2's share (about 0) -> 1
    ```
  - **In plain words**
    - A: NS2 and INDI both fix the same push, so it is fixed twice
    - B: NS2 first, INDI only the remainder; the filter only lines up the timing (the measurement is delayed by the 30 Hz filter)
    - push of 1 / NS2 20 % too high: A 2 / 2.2, B 1 / 1
  - **Simulation (A8, plant force 0.7 / 1.0 / 1.3 × the prediction)**
    - B equals INDI alone (no double count); A adds an upward bias: bump +1.5 … +2.0 cm against +1.2, offset 0.16 – 0.21 cm against 0.08
    - the simulation cannot show B's advantage on the dip: its INDI has no dip (hardware: −10.4 cm)
  - **Implementation (2026-10-17)**
    - one switch `ctrlOmarIndi.ns2_mode` (0 = A, default; 1 = B), one extra filter, one line; same image, S0 – S3 untouched
    - with 0 the controller is byte-identical to the old build (4 logged flights replayed); ARM build clean
  - **Plan:** fly S3 (A) and S3B (B) on A8 and A1, 3 flights each, compare dip and overshoot
  - **Question:** which one is the S3 of the study, or do we report both?
