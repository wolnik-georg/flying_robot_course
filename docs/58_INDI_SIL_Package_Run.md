## Proposed smallest lab test (text only)

**Goal:** Separate (1) attitude stiffness, (2) res_sign, (3) position-loop stiffness on **real A1**, one change per sortie after a common geometric hover check.

**Sortie 0 (abort reference):** Flown baseline — yaml only:

```yaml
# firmware_params (broadcast to study drone, controller=6, ctrl_mode=3)
indi_gains.kr: 2400
indi_gains.kw: 170
indi_gains.fc_bw: 206
indi_gains.filt_dt_us: 1000
indi_gains.filt_prewarp: 1
# res_sign omitted => +1 default (traj_iface.c)
pos.kp_xy: 64
pos.kp_z: 48
pos.kv_xy: 5
pos.kv_z: 7
pos.ki_z: 0
```

**Abort:** manual kill if |roll| or |pitch| &gt; 25° for &gt; 0.5 s, or z &lt; 0.25 m on bottom; if baseline already unstable, do not proceed.

**Sortie 1 (sign only):** Same as Sortie 0 but `indi_gains.res_sign: -1` (only change).

**Sortie 2 (package, never flown):** `res_sign: -1`, `kr: 483`, `kw: 76`, `kp_xy: 40`, `kp_z: 30`, `kv_xy: 8`, `kv_z: 10`, `ki_z: 0`, other filters unchanged.

**Sortie 3 (optional stiffness check):** Sortie 2 but `kr: 987`, `kw: 109`, matched KP 26 / KV 3.2 (2026-09-11 attempt 2 reference).

**Record:** 500 Hz uSD on bottom + radio meta; compare steady 6–13 s gyro RMS and mean z vs Sortie 0.

**Success criterion (lab, not SIL):** Sortie 2 or 3 shows gyro RMS materially below Sortie 0 *and* |mean z err| &lt; 10 cm without position breakup — **hypothesis test**, not proof.
