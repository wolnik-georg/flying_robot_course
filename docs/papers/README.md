# Paper library

The 15 papers cited by the thesis. **The PDFs are gitignored** — 48 MB of third-party work is not
ours to redistribute, and the library is fully reproducible because every entry in
[`../references.bib`](../references.bib) carries its arXiv id.

```bash
./fetch_papers.sh        # rebuild after a fresh clone; skips what is already here
```

Filenames match the BibTeX keys, so `file = {papers/<key>.pdf}` resolves.

**Before citing any of these, read
[`../17_Source_Ledger_and_Citation_Discipline.md`](../17_Source_Ledger_and_Citation_Discipline.md).**
Holding a PDF is not the same as having read it at the level of a claim, and the ledger tracks
which is which. Two misattributions have already occurred in this project, both from trusting our
own summaries instead of the source.

All bibliographic metadata in `references.bib` was generated from the arXiv API rather than typed
from memory. Where the preprint year differs from the published venue year, a `yearnote` field
records both.
