Stage 2 — only if stage 1 passed

one at a time

Each row is one flight, one variable. All are runtime params — no reflash between them. Stop and think at any regression rather than stacking the next change on top.

#SetWhat it tests
ares_fc = 80
res_clamp = 10		 Conditioning the residual before it reaches the attitude command. The one thing NA-INDI does that we never did.
bfilt_prewarp = 1
filt_dt_us = 1000
fc_bw = 206		 A deliberate no-op. Same filtering as today, but now fc_bw means what it says. Confirms nothing changed before any real tuning starts.
cfc_bw < 206 Only after (b). Now the number is honest, so tuning it is meaningful for the first time.
dnotch_en = 1
notch_f0 = 6.9		 Only after (b). The notch previously sat at 13.8 Hz — it has never actually been tested against the 6.9 Hz peak.
ekr = 987, kw = 109
then 632/87		 The shake-band test. Our attitude loop's ωn is 7.80 Hz and the shake is 6.3–7.9 Hz. Lowering kr moves ωn to 5.0 then 4.0 Hz at the same ζ=1.74. If the shake follows, it is the attitude loop. If it stays at ~6.9 Hz, kr is exonerated. Expect worse tracking RMSE — that is the trade being measured.

Do not copy NA-INDI's numbers directly. Their filters carry the same 2× sample-rate error and use a different discretisation, so their "80 Hz" is neither our 80 nor their own. Copy the ratios, not the labels.

Same for the gains. Converted to a common basis ours is 8.2× stiffer than theirs (0.0575 vs 0.0070 Nm/rad) — ωn 7.80 Hz against their 3.28 Hz. A different airframe justifies some of that, not 8×. Ours were tuned for figure-8 tracking against the hover limit; theirs to be comfortable.
