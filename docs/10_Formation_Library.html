§1

Why these scenarios

Downwash is a function of relative geometry: mostly vertical separation, secondarily lateral overlap, and — for anything that moves — the rate those change. A useful set covers all three, and includes cases where the interaction is known to be near zero, so a positive result elsewhere has something to be compared against.

Steady separation while both vehicles moveA2, B1, B2
