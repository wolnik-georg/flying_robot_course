  • Pull both repos on the lab PC (flying_robot_course + crazyswarm2); a stale yaml ruined flight 1 on 10-03.
  • Build from the workspace root ~/georg/ros2_ws; launch ros2 launch crazyflie launch.py (cpp), check CS2_CONNECT_PARAM_PACE_V1.
  • Card THESIS1: umount + fsck.vfat -a; both cards: config.txt = usd_thesis_config.txt, check_usd_deck.py on each drone.
  • Flash the rebuilt binaries from the laptop (build_artifacts/): default e766f0a4…, 100 Hz + timing f7711848…. Stack patch applied first.
  • ros2 topic echo /cf5/pose --once shows a real position before any flight; no Assert failed, no rate is off.
  • cf5 yaml: geometric ctrl_mode=0 + ki_z=16, or full INDI ctrl_mode=3 + ki_z=0. Never ki_z=16 with ctrl_mode=3.

3 — Stop rules

  • Any Assert failed, rate is off, or silent /cf5/pose: land / power-cycle, send the log, do not fly.
  • cf5 tumbles again: stop; do not retry the same config. Compare against the default-firmware flight (flight 2).
  • After a crash: toggle stabilizer.estimator 1 → 2 before the next flight (stuck EKF).
  • Never broadcast usec.reset mid-flight.
